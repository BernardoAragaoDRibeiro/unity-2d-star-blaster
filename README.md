# English Version

## Project Description

Star Blaster is a small **2D space shooter game** developed using Unity as part of the *Complete Unity 2D Developer Course* by GameDev.tv.

The goal of the project is to practice game development fundamentals using Unity and C# through a hands-on learning experience.

In this game, the player controls a spaceship, avoids enemies and obstacles, and shoots targets while progressing through the level.

This project was created for educational purposes while following the course instructions.

Course reference:  
GameDev.tv – Complete Unity 2D Developer Course

## Technologies Used

- Unity Engine: version 6
- C#
- Unity 2D tools
- Unity physics system

## Features Implemented

- 2D space shooter gameplay
- Player movement and shooting mechanics
- Enemy interaction
- Collision detection
- Basic combat systems

## How to Run

1. Install Unity Hub
2. Install Unity Editor version 6
3. Clone this repository

git clone <repository-url>

4. Open the project using Unity Hub
5. Press Play inside the Unity Editor

## Project Structure

Assets/            - game assets, scripts and scenes  
ProjectSettings/   - Unity project configuration  
Packages/          - Unity package dependencies

# Versão em Português

## Descrição do Projeto

Star Blaster é um pequeno **jogo 2D de nave espacial e tiro** desenvolvido na Unity como parte do curso *Complete Unity 2D Developer Course* da GameDev.tv.

O objetivo do projeto é praticar os fundamentos do desenvolvimento de jogos utilizando Unity e C# através de um projeto prático.

No jogo, o jogador controla uma nave espacial, evita inimigos e obstáculos, e ataca alvos enquanto avança pelas fases.

Este projeto foi desenvolvido para fins educacionais, seguindo as instruções do curso.

Referência do curso:  
GameDev.tv – Complete Unity 2D Developer Course

## Tecnologias Utilizadas

- Unity Engine: versão 6
- C#
- Ferramentas 2D da Unity
- Sistema de física da Unity

## Funcionalidades Implementadas

- Jogabilidade de space shooter 2D
- Movimentação e disparos do jogador
- Interação com inimigos
- Detecção de colisões
- Sistema básico de combate
